# VIDEO-MADE-BY-CHARACTERS
VIDEO-MADE-BY-CHARACTERS

A Python script that transforms any video into a character-based ASCII/Unicode animation, where each frame is reconstructed using text characters such as Greek letters, Japanese characters, symbols, and more.

Features:

Convert videos into text-art animations using customizable character sets.
Support for black-and-white and full RGB color output.
Adjustable output resolution and pixelation levels.
Works with various Unicode character collections, including Greek, Japanese, and custom symbols.
Preserves the original video's audio track for a seamless viewing experience.
Generate unique artistic effects ranging from retro terminal-style visuals to colorful Unicode mosaics.

The result is a stylized video where every frame is rendered entirely from characters while maintaining the motion and sound of the original video.
